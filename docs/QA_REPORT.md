# QA report

Verification uses the production Worker and client bundle under Miniflare, disposable D1, and synthetic data. Playwright exercises Chromium on desktop and with an iPhone 15-sized viewport and mobile input emulation.

## Coverage

- Session cookie attributes, unauthorized access, cross-origin writes, bounded request size and cross-tenant access.
- Approval and publication transitions, concurrent correction publication, draft imports and stale-write rejection.
- Contextual chat, fallback, sensitive question routing, strict source selection and AI usage limits.
- Messenger verification token, raw signature, concurrent deduplication and real/test dashboard separation.
- Browser flows for dashboard, chat diagnostics, knowledge imports, product creation and editing, iPhone navigation and mock Messenger replay.

CI retains browser and screenshot artifacts for seven days. Live Cloudflare inference, public deployment, a physical iPhone, and Meta's live webhook service are outside this credential-free verification.
